## Общее для всех сценариев

- Перед каждым тестом `ScenarioTestSupport` очищает базу Redis и ставит часы приложения (`MutableClock`) ровно на начало секунды.
- Срок жизни ключей считает сам Redis по своим часам; тест проверяет остаток срока через `getExpire`.
- Посмотреть, что лежит в Redis, тест может напрямую, через `ReactiveStringRedisTemplate`, а вручную — через `docker compose exec redis redis-cli`.
